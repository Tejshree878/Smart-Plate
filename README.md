# Smart Plate – Personalized Diet & Fitness Web Application

Smart Plate is a front-end web application designed to bring common diet and fitness utilities together in one place.

## Features

- BMI Calculator with category-based diet and supplement suggestions
- Recipe Finder using TheMealDB API
- Recipe ingredients, instructions, images and YouTube video links
- Fitness Routine Recommender based on BMI category and fitness goal
- Grocery Manager for adding, categorizing and removing grocery items
- About Us and Feedback pages
- Responsive front-end interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
- TheMealDB API

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. For the recipe search feature, an internet connection is required because it uses TheMealDB API.
